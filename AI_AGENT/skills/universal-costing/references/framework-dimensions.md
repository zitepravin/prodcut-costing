# Universal costing dimensions (from framework report)

## Formula

Cost Object + Cost Method + Cost Drivers + Cost Sources + Allocation Rules
+ Cost Components + Cost Type + Time/Version = Cost Result

## Component families (configurable)

Direct Material, Direct Labour, Machine/Equipment, Setup/Changeover,
Energy/Utilities, Consumables, Inspection/Quality, Tooling/Fixture,
Subcontract/External Process, Packaging, Freight/Logistics, Overhead,
Value Addition, Commercial, Tax/Duty/Fee, Waste/Scrap/Yield, Finance/Carrying

## Structures (optional modules)

BOM, Recipe/Formula, Routing/Operation, WBS/Project, Service activity tree,
Trip/Route, Contract/Milestone, Asset lifecycle, Hybrid

## Variance categories

Price/Rate, Usage/Quantity, Labour efficiency, Machine efficiency,
Yield, Scrap, Overhead absorption, FX, Supplier, Process, Commercial, Project (budget/committed/actual/forecast)

## Governance

Platform Owner: entitlement of methods/features
Customer Admin: users/roles/config within entitlement
Frozen snapshots: immutable
Historical calc: effective rates + FX asOfDate + config version
